# Kayamrut Farms — admin

Next.js admin panel (Forest Gold ops chrome). Fixture-driven so we can see which Laravel APIs we need.

## Run

```bash
cd admin
npm install
npm run dev
```

Defaults to [http://localhost:3001](http://localhost:3001) (see `package.json`).

## Screens

- Dashboard
- Products (list + edit/new form)
- Categories
- Orders (list + detail / status actions)
- Customers
- Content / CMS stubs

All writes are UI-only until the API exists. See `../docs/api-requirements-draft.md`.
