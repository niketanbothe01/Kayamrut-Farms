# Kayamrut Farms — storefront

Next.js App Router storefront using the **Forest Gold** theme (simple, user-friendly).

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s included

- Home (full-bleed Forest Gold hero)
- Shop + category filters
- Product detail (fixture variants / prices)
- Cart + About shells
- Product fixtures in `src/data/products.ts` (stand-in for Laravel API)

Cart “Add” is UI-only until backend integration.
