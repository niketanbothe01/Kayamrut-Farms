# Kayamrut Farms

Monorepo for Kayamrut Farms — organic superfoods ecommerce.

## Apps

- `frontend/` — customer storefront (Next.js, **Forest Gold** theme)
- `backend/` — Laravel API (not scaffolded yet)
- `admin/` — admin app (not scaffolded yet)
